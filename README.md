# Ledger Service

Домашнее задание по теме 3: «Ввод-вывод (I/O). Обработка ошибок».

## Реализованная функциональность

* **Сущность `Budget`**: структура с полями `Category`, `Limit`, `Period` и хранение в `map[string]Budget`.
* **Управление бюджетами (`SetBudget`)**: добавление и обновление лимитов по категориям.
* **Контроль лимитов (`AddTransaction`)**: подсчет суммарных трат по категории; отклонение операции с возвратом ошибки `ErrBudgetExceeded`, если сумма превышает лимит (транзакция в хранилище не сохраняется).
* **Потоковая загрузка JSON (`LoadBudgets`)**: чтение бюджетов из любого `io.Reader` с обработкой ошибок десериализации. В `main` используется связка `os.Open("budgets.json")` и `bufio.NewReader`.
* **Тестовые сценарии в `main`**: проверка перехвата I/O ошибок, загрузка файла, успешные списания, отклонение операций сверх лимита и проведение транзакций без ограничений.

## Структура проекта

* `main.go` — логика сервиса, структуры данных и демонстрационный сценарий.
* `budgets.json` — файл с конфигурацией бюджетов в формате JSON.
* `ledger_test.go` — модульные тесты для проверки лимитов и парсинга JSON.
* `go.mod` — модуль проекта.
